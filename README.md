## 按你的需要找到入口

- **想了解和使用软件**：从 [树鸭儿项目页](https://github.com/NongNongYaEr/tree-duck)与[使用文档](https://github.com/NongNongYaEr/tree-duck/blob/main/docs/README.md)开始，下载状态以项目说明为准。
- **想研究源码或参与改进**：先看[源码筹备说明](https://github.com/NongNongYaEr/tree-duck/blob/main/docs/source-status.md)，了解当前开放范围与准备进度。
- **想反馈软件问题或制作需求**：使用[故障反馈和功能建议表单](https://github.com/NongNongYaEr/tree-duck/issues/new/choose)，账号、订单与会员问题通过网站的站内反馈处理。

## 官网与 GitHub

官网承接软件下载、会员和配套资产；GitHub 承载项目介绍、使用文档与开发反馈，源码按各项目的实际状态公开。正式官网地址准备好后，会在这里补充入口。

配套资产与软件源码分别维护，具体获取范围和授权以各项目及内容说明为准。
